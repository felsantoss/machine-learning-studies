### Introdução a Machine Learning
- #### **Inteligência Artificial**: Um campo da computação que busca em computadores simular a inteligencia humana.

- #### **Machine Learning**: Um campo da inteligência artificial que ensina maquínas a partir de dados.

- #### **Deep Learning**: Um campo de Machine Learning que aplica o conceito de redes neurais com multiplas camadas para resolver problemas complexos, como reconhecimento de imagem e voz.
